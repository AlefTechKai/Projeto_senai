SENAI Trabalho de Implantação de Sistemas

Esta aplicação web Full Stack foi desenvolvida como trabalho prático do SENAI, focando na implantação, arquitetura de software e integração entre Spring Boot, Angular e PostgreSQL.

🚀 Backend

  • Java 17 — Linguagem principal
  • Spring Boot — Framework de aplicação
  • Spring Data JPA — Persistência de dados
  • Hibernate — ORM / mapeamento relacional
  • REST API — Endpoints GET, POST, PUT, DELETE
  • Maven — Gerenciamento de dependências

⚡ Frontend

  • Angular 19 — Framework SPA
  • TypeScript — Linguagem tipada
  • RxJS — Programação reativa
  • HttpClient — Comunicação com a API
  • Angular Material — Componentes UI
  • SCSS — Estilização customizada

🛢️ Banco de Dados

  • PostgreSQL — Banco relacional
  • @Entity / @Table — Entidades JPA
  • @ManyToOne — Relacionamento Modelo → Marca
  • @JoinColumn — Chave estrangeira marca_id
  • JpaRepository — CRUD automático
